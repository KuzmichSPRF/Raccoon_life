# 🦝 Админ-команды для бота Raccoon Life

## Команды аналитики и отчетов

### 📊 `/report` или `/daily_report`

**Мгновенно формирует и отправляет администратору сводку за последние 24 часа и прикрепленный Excel-файл (.xlsx) со всеми подробными логами.**

- ⏰ Автоматический отчет также приходит **каждое утро ровно в 06:00 по МСК**.
- Включает 5 вкладок:
  1. `📊 Сводка` — KPI пользователей, экономики, игр и донатов.
  2. `💰 Транзакции` — журнал всех начислений и списаний шишек с балансами.
  3. `🎮 Игры` — журнал сыгранных мини-игр и атак босса.
  4. `👥 Пользователи` — база игроков с балансами и уровнем Дупла.
  5. `⭐ Платежи` — история покупок Telegram Stars и TON.

---

## Команды управления шишками

Все команды доступны **только администратору** (ADMIN_ID из .env).

---

### 💰 `/add <username|user_id> <amount> [reason]`

**Начисляет токены пользователю и отправляет уведомление**

#### Параметры:
- `username|user_id` — username (с @ или без) **ИЛИ** ID пользователя в Telegram (обязательно)
- `amount` — количество шишек для начисления (обязательно)
- `reason` — причина начисления (необязательно, по умолчанию "Начисление админом")

#### Примеры:
```
/add @kuzmi 100 За победу в турнире
/add kuzmi 500 Приз за первое место
/add 456789123 50 Бонус за активность
/add 123456789 100 За победу в турнире
```

#### Что происходит:
1. ✅ Шишки начисляются на баланс пользователя
2. 📬 Админ получает подтверждение с новым балансом
3. 📬 Пользователь получает уведомление в боте о начислении

---

### 💸 `/spend <username|user_id> <amount> [reason]`

**Списывает токены у пользователя и отправляет уведомление**

#### Параметры:
- `username|user_id` — username (с @ или без) **ИЛИ** ID пользователя в Telegram (обязательно)
- `amount` — количество шишек для списания (обязательно)
- `reason` — причина списания (необязательно, по умолчанию "Списание админом")

#### Примеры:
```
/spend @kuzmi 50 Штраф за читы
/spend kuzmi 100 Возврат ставки
/spend 123456789 50 Штраф за читы
```

#### Что происходит:
1. ✅ Шишки списываются с баланса пользователя
2. 📬 Админ получает подтверждение с остатком
3. 📬 Пользователь получает уведомление о списании

#### Ошибки:
- ❌ Если у пользователя недостаточно шишек, бот сообщит об этом

---

### 💸 `/give <amount> [reason]` (ответ на сообщение)

**Передает шишки пользователю из баланса администратора.**

#### Параметры:
- `amount` — количество шишек для передачи (обязательно)
- `reason` — причина передачи (необязательно, по умолчанию "Перевод админом")

#### Использование:
Эта команда должна быть использована как **ответ на сообщение пользователя**, которому вы хотите передать шишки.

#### Примеры:
```
/give 100
/give 500 Приз за активность
```

#### Что происходит:
1. ✅ Указанное количество шишек списывается с баланса администратора.
2. ✅ Указанное количество шишек начисляется на баланс пользователя, на чье сообщение был дан ответ.
3. 📬 Админ получает подтверждение с новым балансом обоих пользователей.
4. 📬 Пользователь получает уведомление в боте о получении шишек.

#### Ошибки:
- ❌ Если у администратора недостаточно шишек, бот сообщит об этом.
- ❌ Если команда не является ответом на сообщение, бот сообщит об этом.

### 📢 `/broadcast <text>`

**Рассылает сообщение всем активным (незабаненным) пользователям бота**

#### Параметры:
- `text` — текст сообщения для рассылки (обязательно)

#### Примеры:
```
/broadcast 📢 Завтра стартует новый квест, не пропустите!
/broadcast 🎁 В игре Найди Фишку увеличены награды!
```

#### Что происходит:
1. ⏳ Бот запускает безопасную рассылку (с задержками, чтобы избежать спам-блока от Telegram API).
2. 📬 Активные пользователи получают ваше сообщение.
3. ✅ По завершении админ получает отчет: сколько сообщений доставлено успешно, а сколько пользователей заблокировали бота.

---

### 💳 `/balance <username|user_id>`

**Проверяет баланс пользователя**

#### Параметры:
- `username|user_id` — username (с @ или без) **ИЛИ** ID пользователя в Telegram (обязательно)

#### Примеры:
```
/balance @kuzmi
/balance kuzmi
/balance 123456789
```

#### Что показывает:
- 👤 Имя пользователя и username
- 🆔 ID пользователя
- 💰 Текущий баланс
- 📊 Всего заработано шишек
- 💸 Всего потрачено шишек

## 🔐 Безопасность

- Команды доступны **только администратору** (ADMIN_ID из .env)
- При попытке использования обычным пользователем бот ответит: "❌ У вас нет прав для этой команды!"

---

## 📝 Логи

Все операции записываются в лог бота:
- 🎯 Начисления: `💰 +{amount} Шишек: user_id={id}, reason=admin_grant:{reason}`
- 🎯 Списания: `💸 -{amount} Шишек: user_id={id}, reason=admin_spend:{reason}`
- 🎯 Уведомления: `📬 Уведомление отправлено пользователю {user_id}`

---

## ⚠️ Важные заметки

1. **Пользователь должен быть запущен в боте** хотя бы раз (использовать /start)
2. **Если пользователь заблокировал бота**, шишки всё равно будут начислены/списаны, но уведомление не дойдёт
3. **Username работает с @ и без** — `/add @kuzmi 100` и `/add kuzmi 100` равнозначны
4. **Поиск по имени** — если username не найден, бот попробует найти по first_name или last_name
